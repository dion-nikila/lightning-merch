# Lightning by Neesh — Merch
Serve the repository root with `python3 -m http.server 8000` and open localhost:8000. No build or installation required.

The catalog in shop.js defines each sticker’s name, color, sizes, availability, optional LKR price, artwork and desktop/mobile positions. Positions are percentages of the board. Replace the numbered transparent PNGs in products/ to update artwork. The italic header is a temporary typographic wordmark.

Cart quantities and sizes persist in the visitor’s browser. Products are concepts. Before accepting orders, confirm prices and inventory and connect a server-validated checkout, payment provider and fulfillment process.
